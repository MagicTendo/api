## 🛠️ Features

Here are all of my static APIs! For now, only two are available :

### 🎴 [Yunayunori](https://magictendo.github.io/api/yunayunori.json)

It includes various information about the Yunayunori's games, such as the name, the current version, the release date, the tags, the color, the link, and the logo. If applicable, the leaderboard is included.

### 🎼 [YTPMV](https://magictendo.github.io/api/ytpmv.json)

This API is composed of two big dictionaries, one for the sources, the other one for the songs. The aim of this API is to include as most sources and songs used in YTPMVs and 音MADs as possible. Each source entry includes the name, a link, and an image, and each song entry only has the name and a link.
